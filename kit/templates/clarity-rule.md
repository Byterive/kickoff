## Clarify before you record or build
When a new phase is starting, a new requirement is added, or anything new in this project needs a decision:
1. Stop and ask me first. Do not assume, and never treat one "yes" as covering a point it was not asked about.
2. Give a short numbered brief: for each item the options, your recommendation, and the question. One item per number.
3. Wait for my explicit answer to each number, and restate which number each answer is for.
4. If an answer affects a decision, a phase, a step or a requirement, record it before building: DECISIONS.md (what and why), the plan if there is one (phases and steps), and REQUIREMENTS.md (status and evidence), with the decision noted against its number.
5. If scope is narrowed, merged or dropped, list exactly what is dropped and get an explicit OK.
6. Before saying done, trace each requirement in REQUIREMENTS.md to evidence and report the partial or missing ones yourself.
